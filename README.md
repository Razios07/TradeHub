TradeHub: Full-Stack Stock Trading Platform
A high-performance trading platform clone modeled after the Kite UI, designed for real-time portfolio management and seamless market data visualization.

Key Features:
Real-time Monitoring: Replicates the minimalist Kite dashboard for tracking stock performance and watchlists.

Interactive Analytics: Uses Chart.js to render historical data and performance metrics.

Robust Backend: Secure RESTful API built with Node.js and Express to handle order execution and user portfolios.

Responsive UI: Fully optimized for all device breakpoints using React and Material UI.

Tech Stack:
Frontend: ReactJS, Material UI, Chart.js.

Backend: Node.js, Express.js.

Database: MongoDB (Mongoose).
